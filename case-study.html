Sistema de Gestão Processual

Aplicativo desktop que centraliza notificações e processos judiciais do PDPJ, com controle de acesso, certificados digitais e envio de e-mail integrado.

Electron Node.js + Express PostgreSQL (Railway) API PDPJ / OAuth2 RedTrust + Certificados Microsoft Graph Auto-update via GitHub
Aviso de confidencialidade. Estudo de caso para fins de portfólio. Não contém código-fonte proprietário, credenciais, dados de clientes nem o nome da empresa. Os diagramas e descrições são representações genéricas do funcionamento técnico do sistema.

Arquitetura do sistema

A aplicação segue uma arquitetura cliente-servidor com backend embarcado: o app desktop Electron, instalado na máquina do usuário, sobe um backend Node.js/Express como processo filho e se comunica com ele localmente via HTTP. Toda a lógica de negócio, validação, autorização e integração com APIs externas fica no backend — o frontend é apenas a camada de apresentação.

A persistência é em PostgreSQL, com dados sensíveis (credenciais de integração, senhas SMTP) criptografados em repouso usando AES.

Essa separação garante que segurança e autorização sejam tratadas no servidor, sem confiar no cliente, e centraliza integrações sensíveis — como autenticação OAuth2 com a API PDPJ dos tribunais e envio de e-mails via Microsoft Graph.

O acesso às telas de processos depende da presença de certificados e-CNPJ/e-CPF: o sistema os detecta no Windows Certificate Store (disponibilizados pelo RedTrust) via PowerShell e libera as funcionalidades correspondentes quando estão presentes.

Em palavras simples

Máquina do usuário (jurídico)

Aplicativo Desktop (interno) Electron

Programa instalado no Windows. Por dentro ele sobe um servidor local e abre a tela como se fosse um site (localhost:3000).

Servidor interno Node.js + Express

É o "cérebro" do app: trata login, regras de acesso e conversa com os serviços externos. Roda dentro do próprio computador.

RedTrust + Certificados do Windows Local

Os certificados e-CNPJ/e-CPF só aparecem no Windows quando o RedTrust está conectado. O app verifica isso e libera a aba de Processos.

o servidor interno conversa com cada serviço da nuvem por conexão segura criptografada

Serviços na nuvem (internet)

Banco de dados PostgreSQL · Railway

Guarda usuários, permissões, CNPJs cadastrados e histórico. Fica na nuvem — por isso funciona de qualquer lugar, dentro ou fora da empresa.

API do PDPJ OAuth2

Fonte oficial das comunicações e processos. O app pega um "token" de acesso por CNPJ e consulta as intimações, citações e o inteiro teor.

Microsoft Graph E-mail

Envia o e-mail em nome do usuário e salva uma cópia em "Enviados" do Outlook — sem precisar abrir o Outlook.

GitHub Releases Auto-update

Quando você publica uma nova versão, o app baixa e atualiza sozinho nas máquinas de todos os usuários.

Envio de e-mail integrado

O encaminhamento sai direto do app, sem abrir o Outlook. O sistema tenta primeiro o Microsoft Graph e, se ele falhar, cai automaticamente para SMTP — um fallback que garante resiliência no envio:

flowchart LR U["Usuário encaminha
a partir do processo"] --> S["Servidor
Node.js + Express"] S --> G["Microsoft Graph · OAuth2
(primário)"] S -.->|fallback| M["SMTP / Nodemailer
(se o Graph falhar)"] G --> E["E-mail enviado
+ Itens Enviados"] M --> E E --> DB[("Registro no banco
tabela sent_emails")]

A cópia em "Itens Enviados" funciona de formas diferentes: via Graph é nativa (saveToSentItems); no fallback SMTP, é um BCC para o próprio remetente. Cada envio é registrado na tabela sent_emails.

Termos técnicos

TermoO que é, em linguagem simples
ElectronTecnologia que transforma um site (HTML/CSS/JS) em um programa instalável de computador.
Node.js + ExpressO servidor que processa as regras do sistema. Roda dentro do app, no próprio computador.
PostgreSQLO banco de dados onde fica tudo guardado (usuários, CNPJs, histórico).
RailwayServiço de nuvem que hospeda o banco de dados, acessível pela internet.
APIA "porta de comunicação" que um sistema oferece para outro pedir e receber dados.
OAuth2 / TokenForma segura de provar identidade: troco minhas credenciais por uma "senha temporária" (token) para usar a API.
PDPJPlataforma Digital do Poder Judiciário — a fonte oficial das comunicações e processos.
Certificado digital (e-CNPJ)Identidade digital da empresa, exigida pela Justiça para acessar os processos.
RedTrustSoftware que gerencia os certificados da empresa e os disponibiliza no Windows quando conectado.
Microsoft GraphAPI da Microsoft usada para enviar e-mails em nome do usuário (Office 365 / Outlook).
bcryptTécnica que embaralha a senha antes de salvar, para que ninguém leia a senha original.
2FASegundo fator de autenticação: além da senha, um código que muda a cada 30s (Google Authenticator).
AES (criptografia)Embaralha dados sensíveis (como o Client Secret) no banco; só o sistema consegue ler de volta.
Auto-updateO app se atualiza sozinho ao detectar uma versão nova publicada no GitHub.
